# Unterricht heute

App für die Jugendlichen des Schulhauses In der Höh: Sie zeigt, welche Lektionen heute und am nächsten Schultag gespettet werden oder ausfallen.

- Die Einträge kommen aus einer veröffentlichten Google-Tabelle (CSV-Link in `index.html`, Zeile `var CSV_URL = "";`).
- Erfasst wird über ein Google-Formular, nur von Schulleitung und Sekretariat.
- Es werden keine Namen von Lehrpersonen und keine Gründe gespeichert.

Übersicht für die Schulleitung: Seitenadresse mit `#schule` am Ende.
